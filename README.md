## About

Hi, I’m Franco — a multilingual Full Stack Developer helping startups and businesses build fast, scalable, and easy-to-use web applications.

With over 3 years of experience, I specialize in crafting responsive and accessible interfaces using **React**, **Next.js**, and **TypeScript**, and building solid backends with **Python**, **Node.js**, and **Express**. I’m experienced in working with both relational databases like **PostgreSQL** and **MySQL**, as well as NoSQL solutions like **MongoDB**, depending on the needs of each project.

Currently working as a freelance developer, I help early-stage startups and product teams turn ideas into working, production-ready applications. I’ve contributed to international projects across Europe (🇸🇪 Sweden, 🇳🇱 Netherlands), working on everything from SPAs to complex API integrations and authentication systems.
